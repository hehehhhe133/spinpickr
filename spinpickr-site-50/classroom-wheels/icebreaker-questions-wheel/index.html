Icebreaker Questions Wheel

Fun questions for any group.

One option per line. Min 2, max 15 options.

About this wheel

The first few minutes of a meeting, class or workshop set the tone for everything after. An icebreaker question helps people relax, but it can feel forced when the facilitator chooses it. A wheel makes the question playful and takes the pressure off the person asking.

The starter questions are light and easy to answer, such as favourite meals, dream trips and coffee or tea. They work for strangers meeting for the first time as well as for teams who already know each other well.

Ways to use it

  • Open a team meeting by letting each person spin and answer one question.
  • Use it at the start of a new term to help students learn about each other.
  • Run it at workshops and training days as a quick warm-up.
  • Add your own topic-specific questions, such as 'What is one thing you learned last week?'.

Tips

  • Keep the questions light and never require personal answers; let people pass if they prefer.
  • Answer first yourself so others can see the tone you are looking for.
  • Replace questions regularly if you use the wheel with the same group, so it never feels repetitive.

How to use it

  • Edit the options in the box under the wheel, one per line.
  • Press the centre button to spin. Use the speaker icon in the corner of the wheel to mute the sound.
  • Spin again, or change the list first. Nothing is stored, so refreshing the page resets everything.

Frequently asked questions

Does it work for workplaces?

Yes. It is popular for team meetings, onboarding sessions and remote calls.

Can I add my own questions?

Yes. Type your questions one per line, up to 15 on the wheel.

How long should an icebreaker take?

Usually five to ten minutes. One question per person is enough for most groups.
