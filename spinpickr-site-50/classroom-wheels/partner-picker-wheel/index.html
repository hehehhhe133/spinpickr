Partner Picker Wheel

Pair students for activities.

One option per line. Min 2, max 15 options.

About this wheel

Students tend to work with the same partner every time unless something changes the pattern. Random pairing breaks that habit, exposes students to different viewpoints and makes it easier for quieter pupils to join in.

Enter the names of everyone in the class and spin repeatedly. The first two results form one pair, the next two form the second pair, and so on until the whole class is matched.

Ways to use it

  • Pair students for peer editing, paired reading or lab work.
  • Create new partners at the start of each week to build a friendly class culture.
  • Take three results in a row if you need groups of three for an odd-numbered class.
  • Use it for adult learning, such as role-play partners in a language class.

Tips

  • Remove each name as it is chosen so nobody is paired twice in one round.
  • Announce the rule before spinning that partners are final for the activity.
  • Keep a note of past pairs if you want to avoid repeating the same combinations.

How to use it

  • Edit the options in the box under the wheel, one per line.
  • Press the centre button to spin. Use the speaker icon in the corner of the wheel to mute the sound.
  • Spin again, or change the list first. Nothing is stored, so refreshing the page resets everything.

Frequently asked questions

Can it do groups of three?

Yes. Take three results in a row for a trio.

What if the class has an odd number of students?

Make one group of three, or let the leftover student join an existing pair.

Is every name equally likely?

Yes. Every name on the wheel has the same chance on each spin.
