Christmas Gift Idea Wheel

Spin for a Christmas gift idea.

One option per line. Min 2, max 15 options.

About this wheel

Holiday shopping gets stressful fast, especially when you are buying for many people. Let the wheel give you a starting point, then personalise the result for the person you have in mind.

The default gifts are classic and easy to find: scarves, books, candles, mugs and board games. Edit them for each person on your list, or add a price to each option so every spin stays within your budget.

Ways to use it

  • Pick ideas for colleagues, neighbours and teachers.
  • Add price tags to stay within a budget.
  • Pair it with the Secret Santa wheel for gift exchanges.
  • Make separate wheels for family, friends and coworkers.

Tips

  • Spin early in December so you have time to shop and wrap without the rush.
  • Add a personal touch, such as a handwritten card, to any result.
  • Keep a list of the ideas that come up and save them for next year.

How to use it

  • Edit the options in the box under the wheel, one per line.
  • Press the centre button to spin. Use the speaker icon in the corner of the wheel to mute the sound.
  • Spin again, or change the list first. Nothing is stored, so refreshing the page resets everything.

Frequently asked questions

Can I add a budget?

Yes. Add price tags to the option text.

Does it work for Secret Santa?

Yes. Pair it with the Secret Santa wheel.

Is it free?

Yes. It is free to use and there is no signup.
