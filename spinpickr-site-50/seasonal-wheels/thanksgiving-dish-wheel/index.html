Thanksgiving Dish Picker Wheel

Decide who brings which dish.

One option per line. Min 2, max 15 options.

About this wheel

Potluck dinners go smoothly when dishes are assigned. Add the guests' names to a second wheel to pair people with dishes.

Tip

Spin until all dishes are assigned, and remove each one as it is picked.

How to use it

  • Edit the options in the box under the wheel, one per line.
  • Press the centre button to spin.
  • Spin again, or change the list first.

FAQ

Can I add vegetarian dishes?

Yes, edit the list freely.

Is it for Thanksgiving only?

No, it works for any potluck.
