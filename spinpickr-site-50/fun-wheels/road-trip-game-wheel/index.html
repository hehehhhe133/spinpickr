Road Trip Game Wheel

Beat the boredom on long drives.

One option per line. Min 2, max 15 options.

About this wheel

Long drives need variety. Spin to choose the next game and avoid the endless debate in the back seat.

Tip

Let a different passenger spin every hour so everyone gets involved.

How to use it

  • Edit the options in the box under the wheel, one per line.
  • Press the centre button to spin.
  • Spin again, or change the list first.

FAQ

Is it safe for drivers?

The driver should never use the wheel while driving. Let a passenger operate it.

Can I add games?

Yes, up to 15.
