Netflix Night Picker Wheel

Spin to choose what to watch tonight.

One option per line. Min 2, max 15 options.

About this wheel

Scrolling for half an hour before choosing is a common modern problem. Spin first, then pick from that category.

Tip

Include Rewatch a favourite for nights when you want zero risk.

How to use it

  • Edit the options in the box under the wheel, one per line.
  • Press the centre button to spin.
  • Spin again, or change the list first.

FAQ

Does this connect to Netflix?

No, it is a standalone wheel and works for any streaming service.

Can I add titles?

Yes, add names instead of categories.
