Random Number Wheel

Spin to pick a number from 1 to 10.

One option per line. Min 2, max 15 options.

About this wheel

Need a quick random number for a game, raffle or classroom task? The wheel provides one in a spin and you can change the range.

Tip

For bigger ranges, replace the list with groups such as 1-10, 11-20 and so on, then spin again.

How to use it

  • Edit the options in the box under the wheel, one per line.
  • Press the centre button to spin.
  • Spin again, or change the list first.

FAQ

Can I use it for raffles?

Yes, for casual raffles where it is allowed.

How many numbers fit?

Up to 15.
